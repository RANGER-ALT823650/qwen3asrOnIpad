# Nine-key lexicon data

The bundled `pinyin9.lex` file is generated from the following MIT-licensed
projects. The source data is converted into digit codes and is not modified by
hand in this repository.

- jieba dictionary: https://github.com/fxsjy/jieba
- pypinyin: https://github.com/mozillazg/python-pinyin
- pinyin-data: https://github.com/mozillazg/pinyin-data
- phrase-pinyin-data: https://github.com/mozillazg/phrase-pinyin-data
